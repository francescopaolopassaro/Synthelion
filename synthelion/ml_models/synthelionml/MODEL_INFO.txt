SynthelionML model file
======================
This model is generated by Synthelion's own training pipeline:
  devtools/train_synthelionml.py

Training data: Synthelion's Wikipedia corpora (5 languages).
Ground-truth labels: Synthelion's rule-based SYNTACTIC compressor
  (self-distillation). Architecture is own transformer encoder.
Runtime: fully offline, CPU-only.
